# Codebase

Two top-level folders: `app/` (the Go + Svelte desktop app) and `site/` (the website and user guide). Paths below are under `app/` unless they say otherwise.

## Go (`app/`, `package main`)

| File | What it holds |
|---|---|
| `main.go` | App and main window options, the menu bar with every shortcut (window key bindings on Windows and Linux), `/media/` serving |
| `service.go` | `Messages`, the Wails service: `Call`, sign-in, files, notifications, appearance, zoom. Data folder setup |
| `bridge.go` | The `backend` interface and the `out` event sink |
| `daemon.go` | The libgm client: session, connection, protocol commands, media |
| `demo.go` | Sample backend for `--demo` |
| `model.go` | JSON shapes for the UI, from libgm's protobufs |
| `settings.go` | `settings.json`, window place and zoom |
| `settings_migrate.go` | Converts settings from earlier versions |
| `linkpreview.go` | Link previews: fetches a page's title, picture and icon, never from the local network, and caches them |
| `server.go` | `--serve`: the service over HTTP and server-sent events |
| `window.go` | Minimum size, on-screen check for a saved place, which platforms draw their own title bar, files dropped on the window |
| `webviewauth.go` | Which Google cookies sign-in needs |
| `webviewauth_darwin.go`, `_windows.go`, `_linux.go` | URL and cookies of the sign-in window, per platform |
| `webviewauth_native.go` | Reaches the web view inside Wails' window (Windows, Linux) |
| `appearance_*.go`, `zoom_*.go` | Window light/dark, behind-window blur, page zoom |
| `*_test.go` | Go tests |

## UI (`app/frontend/`)

| Path | What it holds |
|---|---|
| `src/App.svelte` | Layout, window title, keys that aren't in the menu |
| `src/lib/app.svelte.ts` | All state, and everything that talks to the backend |
| `src/lib/go.ts` | The one door to Go: Wails bindings in the app, `fetch` and SSE with `?http` |
| `src/lib/themes.ts`, `src/themes/*.json` | Themes and their schema |
| `src/lib/links.ts` | Finding links in text, and whose links get a preview |
| `src/lib/messages.ts` | Matching sends to the phone's echo |
| `src/lib/popup.ts` | Keyboard and placement for menus and pickers |
| `src/lib/platform.ts` | Shortcut labels per platform (`⌘` vs `Ctrl`), and whether the UI draws the title bar |
| `src/lib/attachments.ts` | Files waiting in the message box: names, repeats, the limit, preview kind |
| `src/components/` | `Sidebar`, `Thread`, `Bubble`, `LinkChip`, `LinkCard`, `Composer`, `Switcher`, `NewChat`, `Viewer`, `SettingsPage`, `Pairing`, `Shortcuts`, `EmojiPicker`, `ConfirmDialog`, `Backdrop`, `WindowControls`, … |
| `bindings/` | Generated by `just bindings`. Don't edit |
| `test/` | UI unit tests (Node test runner, plain TS) |
| `e2e/` | UI tests and the screenshot tour, in headless Chrome against `--demo --serve` |

## Elsewhere

## Conventions

- Comments say why, in plain sentences. Match the file you're in.
- Protocol commands go through `Call(cmd, args)`, not new service methods.
  New service methods need `just bindings` and a case in `server.go`'s `rpc`.
- Anything platform-specific gets a `_darwin.go`, `_windows.go`, or
  `_linux.go` file, with the same function signature on every platform.
- UI colors come from the theme tokens, never literal colors.
