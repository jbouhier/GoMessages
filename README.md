# GoMessages

Google Messages for Mac, Linux, and Windows.  
Native and fast. 

## Install

1. Download your build from the [latest release](https://github.com/jbouhier/GoMessages/releases/latest).
2. Mac: copy `GoMessages.app` to `/Applications`. Windows: unzip and run it. Linux: unpack and run it.
3. Sign in, tap the emoji on your phone. Stays signed in.

## Shortcuts

| Action        | Shortcut          |
| ------------- | ----------------- |
| Settings      | `Cmd+,`           |
| Zoom in / out | `Cmd+=` / `Cmd+-` |
| Reset zoom    | `Cmd+0`           |
| Quit          | `Cmd+Q`           |

## Troubleshooting

* **Pairing mentions Bluetooth**: turn it on, on both computer and phone. Keep them close.
* **Logged out**: pairings expire after weeks of silence. Pair again.
* **Start fresh**: Settings → Unpair, relaunch, pair again.
* **Closing the window doesn't quit**: by design, so messages keep arriving.
  Reopen from the Dock or tray icon, quit with `Cmd+Q`. Change it in Settings.

Privacy: messages stay between your computer, Google, and your phone. The app
sends nothing anywhere else, no telemetry.
